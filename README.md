# Basic Chatbot

A simple Node.js + Express chatbot app with a frontend UI.

## Features
- Express server
- REST API endpoint: `POST /api/chat`
- Static frontend served from `public/`
- Basic message handling for greetings, help, jokes, time, and date

## Run the app

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.
